# CleanOps 360

Plataforma B2B independiente para limpieza, Baureinigung y Facility Services en Suiza.

## Inicio para v0 y Codex
1. Lee `AGENTS.md`.
2. Lee `docs/START_HERE.md`, `docs/ROADMAP.md` y `docs/DELIVERY_PLAYBOOK.md`.
3. Consulta el Product Master, SRS y las especificaciones aplicables **solo a la fase autorizada**.
4. Antes de implementar, identifica requisitos, dependencias, gates, permisos y criterios de aceptación.
5. Empieza por **Fase 0 — Foundation** y presenta un plan; espera autorización antes de programar.

## Reglas
- Vertical slices: UI/UX, frontend, backend, persistencia, permisos y pruebas integradas.
- Pull Requests con revisión independiente de Codex, CI y evidencia E2E.
- No usar mocks como evidencia de funcionalidades terminadas.
- No modificar decisiones de producto ni avanzar de fase sin autorización.
- No mezclar este proyecto con la web de Espacore ni con otros repositorios.

> La documentación en `docs/` se cargará desde el paquete canónico aprobado. Si aún no está presente, no iniciar desarrollo funcional.
