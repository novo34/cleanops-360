# D3 — SHA-256 / 32 bytes / CleanOps 360 evaluation

Status: CANDIDATE_UNAPPROVED. User design direction is evaluated, not installed policy.
Candidate: OTPAuth SHA256 (URI spelling), 32 CSPRNG bytes, issuer "CleanOps 360".
No default is added to config/security-values, verifier or runtime. Enrollment still
requires explicit private policy arguments and a reviewed transaction contract.

## V4 and cryptographic compatibility

Keep exact V4 trial profile: period 30 seconds, 6 decimal digits, window 1 counter each side.
Their existing approval/trial status is unchanged, not promoted to production approval.
The canonical method kind is TOTP; B1-X's explicit algorithm supports SHA1/SHA256/SHA512,
so SHA256 fits that proposal. No canonical DDL is edited, backfilled or executed.
32 CSPRNG bytes provide 256 bits of secret entropy; 52 unpadded Base32 characters encode
them. This does not make a 6-digit online OTP 256-bit: rate limits, attempts, global counter
CAS, context binding and replay protection remain mandatory.

RFC6238 permits HMAC-SHA256 and recommends a key length matching HMAC output.
The explicit candidate matches SHA256 output length. OTPAuth is the existing mature
implementation; tests project published SHA256 8-digit reference vectors to the canonical
6 digits (decimal truncation/modulo), preserve timestamp/counter arithmetic and check drift.
URI tests verify algorithm=SHA256, digits=6, period=30, issuer=CleanOps 360 and exact
32-byte secret round trip. They prove library/format behavior, not authenticator acceptance.
Reference: RFC6238 sections 1/4 and Appendix B, https://www.rfc-editor.org/rfc/rfc6238.

Issuer must match both URI issuer query and account label prefix generated by OTPAuth.
Account label is server-controlled, non-sensitive and unique enough for the user's accounts;
owner must decide its tenant/account naming semantics. Avoid email/PII or browser labels
unless explicitly reviewed. QR/manual secret and URI remain one-time private response
material after COMMIT, never logs, analytics, idempotency replay or public caching.
