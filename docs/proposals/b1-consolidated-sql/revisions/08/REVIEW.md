Concrete blocker: SQL07 reset_password_cas validates a ticket and a recovery HMAC against the ticket-bound tenant/user/credential generation. The private adapter has no approved reader of that context. HTTP-provided tenant/user/version, guessed generation1, direct table SELECT, fake password PREAUTH and a new self-designed encrypted ticket are not acceptable substitutes. This proposal does not authorize a reset or issue an identity-proof receipt.

One new exact signature: `auth_api.password_reset_material(ticket_digest bytea) RETURNS jsonb`. Input is the32-byte SHA256 of an opaque high-entropy ticket issued by existing attest_reset. Output is private `{tenantId,userId,principalId,credentialVersion,expiresAt,requiresRecovery}` or NULL. No password hash, recipient, recovery digest, token, code, session or authorization grant is returned. HTTP must never project this object or log it.
